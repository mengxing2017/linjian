# 学校消息尾部广告

消息广告是追加在推送消息最后的一段文字，不是首页广告位，不需要图片、安卓或小程序功能，也不需要修改 WeKeeper。

## 学校管理员

进入「本校消息广告」，输入 1–50 个 Unicode 字符的单段文案，先保存草稿，再提交平台审核。emoji 按 Unicode 标量计数，表单不接受内部换行或控制字符。广告标识若需要，应写入文案一起审核，系统不会在推送时偷偷增加前缀。

新广告在通过前不会进入消息。修改已有广告会产生候选修订，当前已通过文案继续使用；候选被驳回或撤回不会停止旧版。待审内容不能直接编辑，先撤回再建立新草稿。审核结果及驳回理由在历史中查看。

管理员只能管理有有效管理身份的本校广告；运营和普通成员不能管理。平台可单独禁止本校广告查看或管理权限；管理权限依赖查看权限。

## 平台审核

进入「学校广告审核」，按学校、状态、提交时间筛选，打开详情核对候选全文、当前文案和提交人，再通过或填写原因驳回。审核绑定具体修订和指纹，版本变化后必须重新加载全文，不能自动批准新内容。帖子自动审核策略不影响广告必须平台审核的要求。

平台可填写原因强制下架配置，但不能仅凭平台身份代写学校广告。重新使用已下架内容也必须由学校重新新增并通过审核。

## 删除、长度和重试

- 学校删除无须审核，终止当前配置及其开放候选；删除后重新新增仍需审核。
- 删除仅影响删除事务完成后新冻结的来源消息。已经冻结或已受理消息不会去掉广告，不能承诺撤回。
- 拼接格式为原有完整消息后一个换行，再加广告全文；原消息及其已有链接保持不变。
- 最终消息最多 200 个 Unicode 标量，超过则整段省略广告，原消息仍正常推送。表单预览只是示意，不保证每条消息都有剩余预算。
- 已冻结事件重试使用同一份原始字节，不读取最新广告、不重复追加。广告保存、审核、删除不补发历史帖子。
- 最近采用记录表示本地冻结时是否追加，不等于实际触达；来源已受理也不等于实际发送成功。

发生冲突时保留文案或审核说明，点击重新加载核对最新数据后再手动提交。切换学校不会把旧学校的迟到结果写入新学校表单。
