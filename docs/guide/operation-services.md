# 服务入口、合作与官方营销

本功能在原首页轮播、群二维码之外新增服务运营能力。轮播仍是站内广告，平台和学校均不能给它配置站外链接；群二维码仍只展示图片。第三方小程序、受控 H5、复制服务链接、服务二维码均由独立服务入口提供，不提供任意外部 App、浏览器或 scheme 执行器。

## 平台配置顺序

1. 如有商业合作，先维护合作方与合作项目，再在“服务目标与合作”录入具体服务提供方、用途、强制披露、联系与投诉渠道、授权和资格说明，选择对应合作方、项目及适用学校，添加所需渠道。学校范围留空表示明确授权所有学校，而不是待确认。图标与服务二维码使用本项目素材，不接受远程图片地址。
2. 提交目标版本，由另一位平台管理员核验并批准。提交人与审核人不得相同。修改目标产生新草稿并撤回旧版本，旧入口不会自动重绑；拒绝与撤回均需理由。
3. 服务、赞助或 CPS 项目可配置学校范围、非个人化渠道代码及有效期。合作资料修改会撤回关联目标版本，需生成新版本复审并重新发布入口。链接只编译固定的 `linjian_channel` 与 `linjian_school` 参数，不加入个人标识；二维码沿用审核版本的静态内容。赞助和 CPS 入口强制显示“合作推广”，学校覆盖不能移除。不包含订单回调、佣金、钱包或资金结算。
4. 在“服务入口”配置平台默认或本校入口，选择已批准目标版本及默认渠道，也可选择站内页面或仅展示说明。配置分类、首页精选、副标题、角标、图标及时间窗。
5. 在学校范围核对最终顺序与展示覆盖，按指定学校和时间预览。未保存的入口可独立预览；预览不会提交入口、产生曝光或发起第三方访问。

授权和资格说明是平台留存的审核材料，不代表系统自动获得微信许可，也不会下发给小程序成员。目标撤回或停用后，新解析和素材读取被拒绝；已经缓存并由用户触发的外部访问无法被瞬时撤销。

## 学校管理

学校可新增自己的入口，隐藏平台默认入口，覆盖名称、副标题、角标、图标、分类和精选状态，或恢复默认。未设置的覆盖字段继承平台；副标题和非强制角标允许显式清空，分类可显式设为“不分类”。学校不能替换平台外部目标、修改强制披露、审批目标版本或读取内部合作联系人。

学校混排只写本校入口或本校覆盖，不更改平台顺序。排序必须提交完整集合及集合 token；批量启停携带全部对象版本，任何缺失、越权、不可启用或版本冲突都整体失败。平台停用不能被学校展示覆盖重新启用。

## 小程序访问

首页服务区位于学校头图之后，最多两行四列；更多服务支持分类、搜索和分页。进入服务说明页本身不算访问第三方。用户阅读披露后主动点击渠道按钮，小程序互跳直接在用户手势调用栈执行；H5 页面只接收服务、批准版本、渠道与点击标识并重新向后端解析，不接受原始 URL 参数。二维码地址也绑定素材 ID 与批准版本，旧素材地址不能获得新配置的素材。

链接复制成功不表示浏览器已打开，二维码展示不表示用户已扫码，平台 API 成功不表示第三方服务或交易完成。渠道失败后由用户主动重试或选择其他已批准渠道，不自动换域、打开其他 App 或绕过限制。

## 效果报表

曝光在图片加载且实际进入可视区域后产生，同一账号、学校、入口、展示位置和展示周期去重。显式访问点击、API 成功、取消、失败、复制成功、二维码展示与 H5 可观察加载结果分别记录。每次点击绑定独立 attempt，导航 API 与 H5 加载分别具有幂等终态。事件重试保持原 ID 和载荷，计数不改变入口修订，也不产生来源 Outbox。

日汇总按 `Asia/Shanghai` 自然日记录；开始日包含、结束日不包含，最长一年。平台可跨学校筛选，学校只能查询本校；支持入口、合作方、合作项目、位置及渠道筛选。报告快照有效十分钟，读取分页与 CSV 导出都重新检查当前权限；导出同一快照的全部匹配行，最多五万行。覆盖说明指出启用前或保留期外的不可追溯区间，不把缺失历史显示为零访问。原始事件默认保留八天，日汇总默认保留三百六十五天。CSV 不包含成员身份、完整业务链接参数或内部审核材料。

## 实现结构

新增三份 `20261121` migration，使用独立运营表、学校展示覆盖及事务内汇总。目标版本保留递增版本号、内容摘要和追加式审核记录；渠道作为严格类型的不可变版本配置保存，拒绝额外字段，与任意 `extra` 扩展对象不同。后台可展开版本查看字段差异与审核历史。平台和学校写入以集合 token 与对象 revision 校验，读取、解析与素材授权共用有效性规则。

## 官方营销

平台单独配置官方原生模板广告或自愿激励视频单元，学校在“本校营销”独立启停。营销失败不影响浏览、选校或发帖，也不会降级为第三方外链。

激励目前只允许 `service_theme`：用户自愿完整观看后切换本次服务区配色，不产生现金、积分、可交易资产或服务访问权限。提前关闭没有权益；重复关闭回调不会重复处理。客户端完成事件只标记为 `client_completed`，不作为服务端可信完成证明，不提供有资产价值的奖励。具体场景和单元须经平台实际核验后方可启用。

营销生命周期记录不是官方结算收入；当前未接入官方收入数据，不虚构收益、佣金或第三方成交。真实收入应以官方后台或获授权接口为准。
