# 仿真发帖统计口径

帖子新增总量包含运营仿真创建的仿真发帖，按实际创建时间而非发布时间归属统计窗口；提供小程序、后台直接发布、模拟和未知来源分项。发帖/内容参与人数排除模拟账号，真实用户对仿真发帖的实际互动仍按原规则计入。模拟账号不进入注册和访问活跃事实。撤销只改变当前公开状态，不扣减实际新增记录。

## 统计概览

在管理后台「数据统计 → 统计概览」查看统计。系统管理员默认查看全站，可选择任意正常或隐藏学校；学校管理员和运营人员仅能查看自己管理的学校，多校授权可逐校切换。

## 页面与加载

「数据统计」位于「论坛管理」上方，是独立导航分组，包含统计概览、内容统计、注册统计、活跃统计和仅系统管理员可见的学校对比。

概览显示新增帖子、新增评论、新增注册、访问活跃四项核心指标，并直接用摘要绘制内容量、注册与活跃人数两个比较图，不为绘图加载趋势、状态、学校明细或同比环比。各统计入口分别请求对应指标；对比默认关闭，选择后才请求相应同期。周期明细默认收起，每页 20 行；学校对比按服务端排序、分页读取，每页 20 所学校。学校全集只保留在短期结果快照中供分页和主动导出，不随概览响应传输。

已知全零时仍显示零趋势，指标切换、日期切换和导航保持可用；所选指标全部未知时保留图表卡片及覆盖说明，不画零线。本项目使用独立新库，内容和注册从零开始统计，安装前无记录的期间也计为 0；有可比基数时正常计算增长率。活跃采集缺口或注册学校归属数据缺失时，受影响指标显示不可用。

## 图表查看

所有统计图表使用本地打包的 ECharts，进入页面后按需加载，无第三方脚本或数据上报。图表与明细、CSV 使用同一报表快照。

- **内容统计**：默认显示新增帖子和评论趋势，可切换发帖、评论及内容参与人数；展开当前状态面板查看帖子与评论的审核、展示分类柱图。当前公开量单独说明，不与状态类别相加。
- **注册统计**：可切换新增注册、截至桶末累计注册、新注册参与人数与参与率。累计包含期初基数，不绘制同期曲线；全站可展开注册归属分布，未绑定学校计入“未归属学校”，学校归属数据缺失单独列出。
- **活跃统计**：查看访问活跃与内容参与人数趋势，或单独查看参与率趋势。比例与人数使用独立图，不将两类人数解释为包含关系。
- **学校对比**：当前页横向柱图与表格共用分页数据。选择指标会按该指标降序读取第一页，也可选择升序、使用表头排序或翻页。仅指标降序第一页标注前 20 校，其余页明确为当前页比较。点击学校可进入该指标所属的统计模块，并保留日期范围。

趋势支持折线/分组柱状、系列显示开关与同比/环比虚线；超过 60 桶时默认查看最近 60 桶，可通过区间滑块查看完整期间，同一期间切换图形或指标保留缩放范围。图形、系列、指标模式和缩放在本地完成，不增加统计请求；学校排序、翻页仍由服务器查询。图表中的缺失位置断线，未来周期留空。各图提供「查看图表数据」，支持键盘读取、分页及下钻；即使图表加载失败，指标、数据表和 CSV 仍可使用。

## 指标与日期

统一使用上海时间。选择日、周、月、年或自定义窗口；自定义最多 366 天。图表支持折线/分组柱状、系列开关、环比或同比虚线，点击月份或日期可缩小周期，明细表可横向滚动。

新增帖子和评论包含后来删除、隐藏或拒绝的内容，编辑不算新增；内容参与人数按账号去重。注册人数以首次小程序注册为准，不包含仅创建的后台账号。累计注册包含期初基数，不是当前筛选窗口新增的累计。

注册学校归属在注册时冻结。当前小程序先注册再绑定学校，因此注册后绑定学校的人员仍计入全站“未归属学校”，不会移动到本校历史注册量。“未归属学校”是有效归属，不影响全站统计；仅当注册学校归属数据缺失时，受影响的学校统计显示不可用，不使用当前学校反推。

访问活跃统计小程序成功登录和主动前台行为，排除后台操作、失败请求、心跳和轮询。全站按账号去重，不能把各校或每日人数直接相加。内容参与按内容记录统计，访问活跃按实际采集覆盖范围统计。

## 数据状态与导出

“—”表示该指标不可用或没有可比同期；0 表示无记录；存在实际数据缺口时单独提示，现有记录不冒充完整总量。未来桶留空。进行中周期只统计至数据截至时间，使用相同进度同比/环比。采集延迟、保留期限或故障缺口会显示原因，不能将其当零。

当前审核/展示分布说明本期创建内容“现在”的状态，不表示本期发生的审核次数。CSV 使用同一统计快照，只导出汇总；快照过期后需刷新再导出，学校或账号权限被撤销后不能继续下载旧快照。

## 运维配置

所有统计配置使用 `LINJIAN_STATISTICS_*`，默认读并发 2、超时 15000 毫秒、有界队列 4096、每批 256、快照 600 秒，活跃事实保留至少 25 个月。统计采集和查询失败不阻断论坛业务。

内容和注册无需覆盖确认配置。`ACTIVITY_COMPLETE_FROM` 使用 RFC3339 时间，在核实小程序已接入活跃采集后设置；未设置时，访问活跃不宣称完整覆盖。覆盖确认会持久化；改动配置不会自动删除此前的确认记录，错误确认需由运维修正记录并清理旧快照。

开发数据库验证可运行 `devbox run -- cargo run --locked --manifest-path backend/Cargo.toml --example test_database`，它会新建临时 PostgreSQL，显式设置 `LINJIAN_TEST_DATABASE_URL` 执行既有 `make test-integration`，退出后停止并清理临时库。
