# 业务统计

在管理后台「论坛功能 → 业务统计」查看统计。系统管理员默认查看全站，可选择任意正常或隐藏学校；学校管理员和运营人员仅能查看自己管理的学校，多校授权可逐校切换。

## 指标与日期

统一使用上海时间。选择日、周、月、年或自定义窗口；自定义最多 366 天。图表支持折线/分组柱状、系列开关、环比或同比虚线，点击月份或日期可缩小周期，明细表可横向滚动。

新增帖子和评论包含后来删除、隐藏或拒绝的内容，编辑不算新增；内容参与人数按账号去重。注册人数以首次小程序注册为准，不包含仅创建的后台账号。累计注册包含期初基数，不是当前筛选窗口新增的累计。

注册学校归属在注册时冻结。当前小程序先注册再绑定学校，因此注册后绑定学校的人员仍计入全站“未归属学校”，不会移动到本校历史注册量。无法核实历史归属时显示不可用，不使用当前学校反推。

访问活跃统计小程序成功登录和主动前台行为，排除后台操作、失败请求、心跳和轮询。全站按账号去重，不能把各校或每日人数直接相加。内容参与可以有历史数据，访问活跃从可信采集开始后才可用。

## 数据状态与导出

“—”表示该指标未知或没有可比同期，0 表示确认覆盖后的零；未来桶留空。进行中周期只统计至数据截至时间，使用相同进度同比/环比。采集延迟、未覆盖的历史或故障缺口会显示原因，不能将其当零。

当前审核/展示分布说明本期创建内容“现在”的状态，不表示本期发生的审核次数。CSV 使用同一统计快照，只导出汇总；快照过期后需刷新再导出，学校或账号权限被撤销后不能继续下载旧快照。

## 运维配置

所有统计配置使用 `LINJIAN_STATISTICS_*`，默认读并发 2、超时 15000 毫秒、有界队列 4096、每批 256、快照 600 秒，活跃事实保留至少 25 个月。统计采集和查询失败不阻断论坛业务。

`CONTENT_COMPLETE_FROM`、`REGISTRATION_COMPLETE_FROM`、`ACTIVITY_COMPLETE_FROM` 使用 RFC3339 时间，仅在核实相应历史或全部使用中的小程序版本均已接入后设置。未设置时，内容/注册仅保证迁移安装后的覆盖，访问活跃不宣称完整覆盖。覆盖确认会持久化；改动配置不会自动删除此前的确认记录，错误确认需由运维修正记录并清理旧快照。

开发数据库验证可运行 `devbox run -- cargo run --locked --manifest-path backend/Cargo.toml --example test_database`，它会新建临时 PostgreSQL，显式设置 `LINJIAN_TEST_DATABASE_URL` 执行既有 `make test-integration`，退出后停止并清理临时库。
