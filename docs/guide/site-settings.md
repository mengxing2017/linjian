# 站点品牌与备案版权

站点设置位于「系统管理 → 站点设置」，生效范围固定为全平台，不随当前学校切换。网站名称、备案和版权属于平台运营信息，与学校资料分别维护。

## 读取与权限

- 品牌、ICP 备案、公安备案和版权等公开展示字段无需登录即可读取，登录页、后台页头、社区入口和统一页脚使用同一份配置。
- 完整配置、修改、清空和变更记录仅平台管理员可操作。学校管理员、运营人员、普通成员和匿名访问者不能写入。
- 页面不显示学校选择器；平台管理员没有学校或学校停用时仍可进入设置。

## 配置项

「站点品牌」包含网站名称、浏览器标题副标题和登录页简介。网站名称为空时，页头、登录页和社区入口不显示品牌文字及空容器，不回填 `Linjian`。

「备案信息」包含 ICP 备案号和公安联网备案。ICP 查询入口固定为 `https://beian.miit.gov.cn/`。公安备案号与查询链接必须同时填写或同时清空，链接必须是以 `https://beian.mps.gov.cn` 开头的官方查询地址。公安备案图标使用受控静态资源，不从后台上传 HTML 或脚本。

「版权信息」包含版权所有者、起始年、截止年模式和补充声明。所有者为空时整组版权信息不生效；清空所有者会同时清空年份、模式和补充声明。自动模式按 `Asia/Shanghai` 计算截止年，跨年后在下一次配置重验时更新。

所有文本项留空或只有空白时视为未填写，对应文字、标题、图标、链接和分隔符整体隐藏。

## 保存与并发

保存需要当前版本号。重复提交相同值不会增加版本；两名管理员同时编辑时，后提交的旧版本会收到冲突提示，需要重新加载后人工合并。保存结果、当前页页头、浏览器标题和页脚立即更新，其他活跃页面在正常网络下约 5 分钟内重验。

清空已有的 ICP、公安备案或版权信息前会显示确认。变更记录保留操作人、时间、版本、变更字段和清空字段；恢复旧值需人工核对后重新编辑保存，不提供一键回滚。

## 边界

站点设置不产生 Outbox、发送任务或帖子变更，不修改学校资料、应用标识、Cookie、缓存键、API 路径、数据库名或来源凭据。小程序名称、静态帮助文档和首个 HTML 响应中的品牌不在本期动态同步范围。

配置不进入离线快照导出导入；该项属于过渡设计，本期不做。
