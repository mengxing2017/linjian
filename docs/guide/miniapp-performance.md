# 小程序页面性能边界

本轮改动对应 `report/小程序页面主线程阻塞与卡顿机制审查报告.md`，仅调整独立 Linjian 小程序，不改变后端契约、鉴权或学校边界。

## 列表与正文

- 信息流、搜索、评论、消息各分类、学校目录与服务目录，每组最多保留三页。组内继续追加，跨组替换旧节点；上一组重新请求该组第一页，随后可以继续加载，历史内容不会仅因客户端截断而不可达。
- 第三页的继续加载按钮显示“下一组”；后续组提供“上一组”。切组后滚动到列表开始，评论切组滚动到评论区。
- 信息流与搜索的页面模型将正文限制为 240 个 Unicode 码点加省略号，详情仍独立读取完整正文。列表卡片也独立限制摘要，避免其他调用者误传全文。
- 这不是服务端摘要接口：原始 HTTP 响应和 JSON 解析仍可能包含全文。没有修改 Rust/TypeScript/fixture 契约；如真机测得响应解析仍是瓶颈，再同步推进列表专用契约，不能宣称本轮已降低网络响应大小。

## 草稿

- 标题最多 200、正文最多 20000 个 Unicode 码点；原生输入长度限制按双 UTF-16 单元的上界设置，再由输入处理统一裁剪，避免切开 emoji 的代理对。
- 退出检查使用编辑版本号，不再序列化完整正文比较快照；相同草稿成功保存后，重复隐藏不会再次写入或申请图片保留。
- 保留同步存储作为离页可靠保存路径，但限制写入规模。保存失败不记为成功，取消退出仍不能丢弃未保存内容。
- 超限旧草稿可以恢复检查，但拒绝覆盖保存并提示缩减；不会在恢复时静默截断并覆写旧草稿。

## 图片与曝光

- 信息流图片通过可视区域观察器在接近视口时才调用私有图片下载；不是仅设置原生图片懒加载。离开、换源或切学校后，旧观察回调与旧请求结果不能更新当前图片。
- 媒体缓存使用 LRU，预算为 48 个文件、32 MiB；品牌图和头像各为 24 个文件、16 MiB。相同 scope/资源的下载会合并。
- 显示中的资源由组件或页面 owner 保留；组件在卸载/换源时释放，服务等页面级 owner 在隐藏/组替换时释放。缓存根页中仍挂载的图片继续保留引用。只淘汰无人使用的文件，因此全部资源都在使用时允许临时超过预算，不能删掉仍被页面引用的文件。
- scope 改变立即失效缓存；晚到的文件结果被清理，不能带入新学校/账号。文件读写与删除仍为异步 API。
- 服务与首页图片最多三项并发读取，合并路径状态更新；服务已曝光后断开对应观察器。统计仍是 best effort，不作为渲染或导航授权。

## 状态同步

- 多条脏帖最多三个并发读取，完成后按最新失效版本检查并一次合并列表；未变化帖子的对象保持不变。切学校、切账号或更新版本后，旧结果不得清除新失效记录。
- TabBar 保留安全状态同步 watcher，但按实例只提交变化字段，菜单常量不再反复发送；重复 attach 不重复 setData。
- 首次信息流 show 已校验学校后，不再为同一次列表加载重复校验；其他独立入口仍保留学校请求与访问权限验证。

## 验证与后续测量

自动化测试覆盖三页边界及回退、摘要/草稿 Unicode 边界、重复保存和失败保护、可视加载、缓存淘汰与晚到写入清理、受控并发、脏帖一次提交、TabBar 差量更新，并保留原有行为测试。

相关命令：

```sh
pnpm --dir frontend/apps/miniapp test
pnpm --dir frontend/apps/miniapp typecheck
pnpm --dir frontend/apps/miniapp lint
pnpm --dir frontend/apps/miniapp build
```

真机仍须按原审查报告验证低端 Android/iPhone 的长列表、草稿、图片长会话与慢网场景。同步 JSON 解析属于未实测的大载荷风险，本轮不引入 Worker、不改写错误语义，也不将性能验收加入业务运行门禁。
