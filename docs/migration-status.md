# Linjian 实施状态

本次实现 P0/P1 与 P2 所需的代码及演练工具；不代表已完成 P3 的真实生产迁移。没有连接生产数据库、切换真实域名、发布微信小程序、登记来源密钥或发送微信群消息，wekeeper 未作本次拆分变更。

| 范围 | 本项目实现 |
| --- | --- |
| 论坛内容与社交 | community：帖子、评论、点赞收藏、关注、通知、举报反馈及审核治理 |
| 论坛管理全部功能 | React 管理后台：内容审核、评论审核、举报反馈、展示资源和屏蔽词、平台默认展示配置 |
| 学校管理与设置 | schools：学校主数据、配置、学校选择、成员角色、授权及学校审计 |
| 登录账号管理 | identity：账号创建、状态管理、学校权限查询、重设密码；平台管理员和普通账号区分；独立会话、Origin/CSRF |
| 企业成员身份映射 | 可选独立目录配置、绑定/解绑、核验和 OAuth；不迁入群发送能力 |
| 完整小程序 | 所有原目录文件迁入；页面、features、transport、媒体、资源、配置、测试和构建均保留；详情见 JSON 清单 |
| 独立契约 | @linjian/api-contract；只保留论坛、资源、身份及来源协议，客户端不跨仓 import |
| 独立数据库 | 两份 forward-only migration；无手机、客户群、模板或发送任务表 |
| Outbox | 事务事件、稳定序号、版本与撤回、冻结正文、签名投递、退避、收件查询、发件列表及重试 |
| 数据迁移 | 只读一致快照导出、空目标原子导入、媒体与全表核对、历史不入队、会话不迁移 |
| 运行交付 | 独立 Makefile、Compose、Dockerfile、环境示例、CI、帮助页及 ADR |

## 本次验证记录

- Rust：格式检查、Clippy（告警视为错误）、9 项单元测试及 1 项路由边界测试通过。
- API 契约：类型检查、无 DOM 平台检查及 33 项测试通过，包含独立生成的 HMAC 签名向量。
- Web：类型检查、ESLint、生产构建通过；原有 47 项回归测试及新增 1 项 Outbox 展示测试通过。
- 小程序：类型检查、ESLint、12 项测试和微信小程序生产构建通过；原目录迁移清单见 `miniapp-migration-manifest.json`。
- 前端边界检查与工具测试通过。
- PostgreSQL 17 单用户模式：两份真实迁移及论坛/Outbox 事务断言通过，覆盖回滚、版本与撤回、学校停用恢复、历史导入和媒体字节往返。

环境禁止监听 TCP 和 Unix 套接字，数据库 HTTP 集成测试已经编译，但未在本环境执行；可用 `make test-integration` 指向显式隔离的测试库，或使用 `tools/test_database.py` 临时建库运行。Docker 镜像与 Compose 尚未在本环境运行验证。

真实接收端联调、完整数据库 HTTP 集成、真实快照迁移演练、平台凭据核验、小程序开发者工具测试及生产入口切换仍需对应环境。上述检查不替代 P3 生产迁移验收，也不授权提前修改 wekeeper。
