# ADR 0001：Linjian 独立论坛

状态：已实现代码边界；生产数据迁移和入口切换尚未执行。

论坛独立为 linjian，使用独立数据库、账号会话、依赖包、环境变量、镜像与 Compose 卷。原项目只作为只读迁移来源。本次不修改 wekeeper，不为联调提前新增其来源接入。

论坛管理全部内容、学校管理、学校设置、学校成员与权限、登录账号管理及整个小程序均迁入本项目。后台当前的 feature 或菜单分组不决定业务归属。

学校资源原有的预览与发布事务已移入 schools 自己的 adapter，不依赖 distribution。企业通讯录仅保留账号身份映射和可选独立 OAuth；客户群、发送策略、发送任务、手机模块及其数据库表和 contract 均不带入。

论坛新库使用独立基线，不复制混合迁移链。历史数据导入不生成 Outbox，不继承会话或机器凭据；媒体原始字节、内容、学校关系与业务 ID 可保留。不同微信 AppID 的 openid 不能直接复用，必须先显式映射。

Outbox 为本论坛数据库内的事务事件。帖子变化和事件同事务提交，投递使用至少一次语义、稳定事件 ID、冻结字节和签名；接收端负责来源去重、版本投影和独立发送确认。来源凭据不获得发送权限。收件和发送结果分别显示，无法保证撤回群内已发送消息。

生产迁移未完成之前不改造 wekeeper。实际生产迁移与入口切换不由本次编码自动执行；发布验收属于研发流程，不进入业务门禁。
