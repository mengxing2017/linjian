Linjian 使用帮助

学校设置保存学校名称、审核方式与主题。学校管理员查看本校成员与角色；平台管理员办理成员授权与撤销。学校角色不自动成为转发权限。

小程序用户管理

在学校管理模块打开用户管理，查看本校微信小程序注册用户的头像、昵称、手机号、学校、发帖数、创建时间和正常/封禁状态。操作员只读，学校管理员可填写原因封禁和解封本校用户。封禁后小程序会话失效，解封后需重新登录；历史内容不会自动下架。手机号为用户自行登记，未验证归属。平台管理员可切换全部学校/未绑定范围，并填写原因纠正手机号或所属学校；学校纠正不搬迁历史内容。后台登录账号及学校管理角色仍分别在对应入口管理。
