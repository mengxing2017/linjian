学校消息尾部广告

这是追加在原有推送消息最后的一段文字，不是首页广告位，不涉及安卓、小程序或其他广告平台。

学校管理员

进入「本校消息广告」，填写 1–50 个 Unicode 字符的单段文案，保存草稿后提交平台审核。需要广告标识时请写进文案一并审核，系统不会在推送时增加未审核文字。

新增、修改必须由平台管理员通过。待审时旧通过版本继续使用，待审文案不能直接编辑；先撤回，再建立新草稿。驳回理由及修订全文在历史中查看。

仅有效本校管理员且持有广告权限的账号可以操作，运营无权管理。冲突时会保留输入，请重新加载并核对后手动提交。

平台管理员

进入「学校广告审核」，按学校、状态、提交时间筛选。打开详情核对候选全文、当前文案和提交人，再通过或填写原因驳回。版本变化必须重新读取，不能自动批准新内容。

平台可填写原因强制下架，但不能仅凭平台身份代写学校广告。帖子自动审核策略不使广告自动通过。

消息、删除与重试

  • 格式是原有完整消息后一个换行，再追加已通过广告全文。原有链接不移动、不截断。
  • 总长超过 200 个 Unicode 字符时整段省略广告，原消息照常推送；效果预览只是示意。
  • 学校删除无须审核，仅影响删除完成后新冻结的消息。已经冻结或已受理消息不承诺撤回。
  • 编辑、通过、删除广告不补发历史帖子，已冻结事件重试不换文案、不重复追加。
  • 最近采用记录及来源受理不是实际触达证明，也不授予来源重试或发送权限。
