站点设置

「系统管理 → 站点设置」维护全平台网站名称、浏览器标题副标题、登录页简介、ICP 备案、公安联网备案和版权信息。生效范围为全平台，不显示学校选择器。

读取与权限

公开展示字段无需登录即可读取，用于登录页、后台页头、社区入口、浏览器标题和统一页脚。完整配置、修改、清空及变更记录仅平台管理员可操作；学校管理员和运营人员即使直接调用接口也不能保存。

填写规则

所有字段可留空。留空或只有空白时，对应文字、标题、图标、链接和分隔符整体隐藏，不回填默认品牌。网站名称最多 30 个字符，副标题最多 40 个字符，登录页简介最多 100 个字符。

ICP 备案号最多 64 个字符，查询入口固定为 https://beian.miit.gov.cn/ 。公安备案号与查询链接必须同时填写或同时清空；链接必须是 https://beian.mps.gov.cn 的官方查询地址。版权所有者、起始年、截止年模式整组生效；清空所有者会清空整组版权信息。自动截止年按上海时间计算。

保存与并发

保存使用当前版本号。重复提交相同值不会增加版本；其他管理员已保存时，旧版本会收到冲突提示，需要重新加载后合并。清空已有备案或版权信息前会确认。变更记录展示操作人、时间、版本和字段变化；恢复旧值需人工核对后重新编辑保存。

边界

站点设置不产生 Outbox、发送任务或帖子变更，不修改学校资料、应用标识、Cookie、缓存键或来源凭据。配置不进入离线快照导出导入；小程序名称、静态帮助文档和首个 HTML 响应中的品牌不在本期动态同步范围。
