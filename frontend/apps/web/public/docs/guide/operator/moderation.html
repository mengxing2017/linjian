内容管理

选择当前学校，在「内容管理」顶部查看帖子、评论各自的审核模式。平台管理员或本校管理员可保存模式，运营人员可查看和审核。

人工审核：投稿进入待审，通过后展示。自动审核（自动通过）：通过基础校验后直接展示。切换只影响之后的新投稿和实际内容编辑，不批量批准历史待审，不恢复被拒绝或隐藏的内容。

「内容管理」包含帖子管理和评论管理。帖子管理默认展示全部未删除帖子，可添加、编辑、删除、置顶、调整状态、排序和导入，并可按审核状态等条件筛选；评论管理默认展示全部未删除评论，可分别筛选审核状态与显示状态。审核帖子时，进入详情读取最新全文和附件后再审核。附件失败请重试，通过必须对应当前版本；遇到冲突应重新加载并核对全文。

自动通过的内容仍可人工拒绝、撤销审核或隐藏；审核详情标记人工、自动或历史决定。审核通过只使内容可展示；来源推送在后台处理，不产生向微信群发送的任务或授权。

举报与反馈

列表展示标题 / 名称、举报原因、举报人、学校、处理状态、举报时间和处理时间，可搜索标题、内容和举报人，并按处理状态筛选。反馈使用“意见反馈”标题和反馈标记。

打开详情核对完整原因、联系方式和附件后填写处理说明，选择已处理或已驳回。处理时间由服务端记录；历史记录未留存时显示“—”。版本冲突会保留草稿，需重新加载案件后再处理。

评论管理可独立设置显示状态为正常或隐藏，不改变审核状态。只有审核通过且正常的评论会公开展示；隐藏评论不计入公开评论数，也不能回复或点赞。
